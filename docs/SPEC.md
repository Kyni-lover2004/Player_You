# Omen — музыкальный плеер с загрузкой из YouTube

Спека после гриллинга. Дата: 2026-08-23. Платформа: macOS.
Расположение: `/Users/egor/Documents/Projects/omen`

## Решения

| Вопрос | Решение |
|---|---|
| Форм-фактор | Десктоп-приложение на Tauri v2 |
| Фронтенд | React + TypeScript, всё состояние плеера в одном сторе |
| Воспроизведение | HTML5 `<audio>` в вебвью, файл через `convertFileSrc` (asset-протокол Tauri — корректный HTTP Range, значит честная перемотка) |
| Формат | mp3 320 CBR. CBR обязателен: точный seek байтовой арифметикой. Битрейт — константа в конфиге |
| Бинарники | ffmpeg — sidecar в бандле. yt-dlp — качается в `~/Library/Application Support/omen/bin`, мимо подписи, чтобы мог обновляться |
| Хранилище | SQLite — источник правды. Аудиофайлы рядом в папке. Сверка с диском при старте |
| Обложка | Превью YouTube, центральный кроп в квадрат |
| Названия | Авточистка (`artist - title`, срез мусора в скобках) + экран ручного редактирования трека |
| Загрузки | Фоновая очередь с прогрессом по каждой позиции, музыка не прерывается |
| Ссылка с `&list=` | Диалог: весь плейлист или одно видео |
| Раздача | Себе и паре друзей. Публично не выкладывать |
| Имя | Отображаемое имя и bundle id развязаны — переименование стоит одну строку |

## Оформление

- **Токены.** Одна фиксированная схема CSS-переменных. Любая тема — встроенная или своя — просто заполняет её значениями.
- **Десять встроенных тем.** 1 Аметист (фиолетовый на чёрном, дефолт) · 2 Полночь · 3 Неон · 4 Уголь · 5 Закат · 6 Хвоя · 7 Гранат · 8 Сепия · 9 Бумага (светлая) · 10 Лёд (светлая).
- **Свои темы.** Пользователь задаёт только фон (цвет или градиент) и акцент. Цвета текста и поверхностей вычисляются из яркости фона — нечитаемую тему собрать невозможно.
- **Градиенты ровно в трёх местах:** фон полноэкранного вида, кнопка play, полоса прогресса. Больше нигде.
- **Полноэкранный вид — гибрид.** Фон = сильный блюр обложки + плотный слой цвета темы поверх. Обложка даёт формы, тема даёт цвет; приложение остаётся цельным на всех экранах.

## Семантика плеера (принято)

- Шафл + повтор всех, конец списка → перемешать заново
- Выключил шафл посреди трека → текущий доигрывает, следующий = сосед по исходному порядку
- Повтор одного + «вперёд» → следующий трек, режим не сбрасывается
- Ручная очередь имеет приоритет над шафлом, играет следующей
- Удалил играющий трек из плейлиста → доигрывает, потом следующий
- Перемотка на паузе → пауза сохраняется
- Перемотка в конец ≠ «трек закончился». Автопереход только по настоящему `ended`
- «Назад»: первые 3 секунды → предыдущий трек, дальше → в начало текущего
- Каждая загрузка трека помечается токеном поколения; результат устаревшего токена отбрасывается (защита от гонок при быстром перелистывании)

## Порядок работ

0. **Вертикальный срез.** Скелет Tauri → вызов yt-dlp по одной ссылке → mp3 на диске → воспроизведение через `convertFileSrc`.
   *Готово, когда:* перемотка в произвольную точку 5-минутного трека мгновенна и точна, ползунок не врёт, повторный seek не перекачивает файл.
1. SQLite, библиотека, теги ID3, обложка, авточистка названий.
2. Движок воспроизведения: очередь, повтор, шафл, токены поколения. Таблицу состояний покрыть тестами.
3. Система тем: токены, десять встроенных, переключение в настройках.
4. UI: список, мини-плеер, полноэкранный вид с кропом, блюром и тинтом.
5. Фоновая очередь загрузок, прогресс, диалог плейлиста, обработка ошибок yt-dlp.
6. Плейлисты, редактирование трека, редактор своих тем.
7. Горячие клавиши. **Последним** — медиа-клавиши и Now Playing (objc, может уехать в v2).

## Риски

- **yt-dlp** — единственная неконтролируемая часть. YouTube ломает его регулярно. Отвал должен давать внятную ошибку в UI, библиотека продолжает играть.
- **Нотаризация macOS** — подписанный бандл не может обновить сам себя. Поэтому yt-dlp вынесен из бандла.
- **Пограничные случаи скачивания** — live-стримы, видео с возрастным ограничением, приватные, многочасовые. Каждый = понятное сообщение, не краш очереди.
- **Дубликаты** — ключ уникальности: YouTube video id.
- **Файл удалён мимо приложения** — сверка при старте, трек помечается как отсутствующий, не пропадает молча.
- **Тинт полноэкранного вида** — плотность слоя придётся подбирать глазами: слишком слабый и тема пропадает, слишком плотный и обложка превращается в пятно. Это единственный параметр, который нельзя посчитать, только увидеть.
