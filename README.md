# Omen

**Музыкальный плеер, который забирает звук из видео по ссылке**

Десктопное приложение для macOS: вставляешь ссылку на видео — получаешь трек
в своей библиотеке, с обложкой, разобранным названием и точной перемоткой.

</div>

---

## Что умеет

**Библиотека**
- Скачивание звука по ссылке на видео в mp3 320 CBR
- Фоновая очередь загрузок: музыка не прерывается, готовые треки появляются сами
- Обложка из превью — вписанная целиком, а не обрезанная
- Автоматическая чистка названий: `MORGENSHTERN - TATU (Lyrics + Eng Subs)` → исполнитель и название по отдельности
- Ручная правка названий, защищённая от повторной автоочистки
- Поиск по названию и исполнителю
- Альбомы — сборники, которые собираешь сам

**Воспроизведение**
- Повтор: выключен, все, один
- Шафл, очередь «играть следующим», громкость
- Перемотка с точностью до кадра формата

**Оформление**
- Десять встроенных тем плюс редактор своих
- Фон подстраивается под обложку текущего трека, оставаясь внутри темы
- Режим погружения: коллекция убирается, сцена занимает всё окно

## Клавиши

| Клавиша | Действие |
|---|---|
| `Пробел` | Играть и пауза |
| `←` `→` | Перемотка на 5 секунд |
| `⇧` + `←` `→` | Предыдущий и следующий трек |
| `↑` `↓` | Громкость |
| `M` | Заглушить |
| `S` | Шафл |
| `R` | Повтор |
| `⌘F` или `/` | Поиск |
| `Esc` | Закрыть и отменить |
| `?` | Подсказка по клавишам |

Буквы работают в любой раскладке: `ы` там же, где `s`.

## Что нужно установить

Приложение вызывает два внешних инструмента.

**macOS**

```bash
brew install yt-dlp ffmpeg
```

**Windows**

```powershell
winget install yt-dlp
winget install ffmpeg
```

`yt-dlp` стоит время от времени обновлять — YouTube меняет формат страниц,
и старая версия перестаёт скачивать:

```bash
brew upgrade yt-dlp
```

На macOS приложение ищет их сначала в `/opt/homebrew/bin` и `/usr/local/bin`,
и только потом в `PATH`. Так сделано намеренно: приложения, запущенные из
Finder, не наследуют `PATH` из терминала, и поиск только по нему молча
провалился бы. На Windows `PATH` наследуется, поэтому там он основной, а
типичные каталоги winget, scoop и chocolatey служат подстраховкой.

## Запуск

Нужны [Node.js](https://nodejs.org) 20+ и [Rust](https://rustup.rs).

```bash
npm install
npm run tauri dev
```

## Сборка

```bash
npm run tauri build
```

**macOS.** Приложение появится в `src-tauri/target/release/bundle/macos/Omen.app`,
образ для передачи — в `bundle/dmg/`.

**Windows.** Исполняемый файл появится в `src-tauri/target/release/omen.exe`,
установщик — в `src-tauri/target/release/bundle/`. Собирать нужно на самой
Windows: компоновщик MSVC с других систем недоступен. Для отрисовки окна
нужен WebView2 — на Windows 11 он встроен, на Windows 10 его доставляет
установщик.

Сборка не подписана сертификатом разработчика, поэтому при первом запуске на
чужой машине macOS её заблокирует. Снимается один раз:

```bash
xattr -cr /Applications/Omen.app
```

## Тесты

```bash
npm test                        # логика плеера, тем и клавиш
cd src-tauri && cargo test      # база, разбор названий, скачивание
```

Тестами закрыто то, что иначе пришлось бы проверять на слух: правила
переключения треков, дедупликация библиотеки, разбор ютубных заголовков,
контрастность любой темы и разбор горячих клавиш.

## Где что лежит

| Что | Где |
|---|---|
| Музыка | `~/Music/Omen/` |
| Обложки | `~/Music/Omen/covers/` |
| База библиотеки | `~/Library/Application Support/com.egor.omen/omen.db` |
| Тема и громкость | хранилище приложения |

Файлы можно свободно перекладывать и удалять: при запуске приложение сверяет
базу с диском и помечает пропавшие треки, не теряя записи о них.

## Устройство

```
src/                 интерфейс на React
  player/            машина состояний, громкость, клавиши
  theme/             вывод цветов темы и её хранение
src-tauri/src/
  db.rs              SQLite: треки и альбомы
  titles.rs          разбор ютубских заголовков
  downloads.rs       очередь загрузок, yt-dlp и обложки
  lib.rs             команды для интерфейса
```

Логика воспроизведения вынесена в чистые функции без React и без
аудиоэлемента, поэтому проверяется целиком, без запуска приложения.

## Чего нет

- **Готовая сборка только под Apple Silicon.** Универсальный бинарь для маков на Intel и сборка под Windows требуют запуска на соответствующей системе; код к обеим готов.
- **Нет подписи разработчика**, поэтому нужен `xattr` при первом запуске.
- **Нет метаданных об альбомах.** YouTube их не сообщает, поэтому альбомы здесь — сборники, собранные руками, а не сведения из справочника.
- **Нет медиа-клавиш** на клавиатуре Mac и виджета Now Playing.

## О правах

Omen — личный инструмент. Скачивание с YouTube нарушает условия
использования сервиса, а скачанная музыка остаётся объектом авторского права
своих владельцев. Пользуйтесь этим для личного прослушивания и не
распространяйте полученные файлы.
